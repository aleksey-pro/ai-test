# Этап 12. Генерация Playwright-тестов

Перед генерацией снимается SHA-256 snapshot существующих `.spec.ts`. Затем `playwright-test-generator` создаёт или обновляет тесты с учётом результатов pre-check и evidence manifest.

Целевое размещение:

```text
autotest-cli-data/tests/
```

После генерации проверяется покрытие: каждому выбранному Markdown-кейсу должен соответствовать `spec.ts`. При отсутствии соответствия недостающий тест создаётся по правилам generator.
