# Этап 13. Визуальные проверки и узкий scope

Для кейсов с визуальным ожидаемым состоянием проверяются DOM, CSS и геометрия, после чего добавляется screenshot контейнера.

Сравнение snapshot «до/после» определяет статусы `created`, `modified` или `unchanged`. Первичный `test-scope` строится только по созданным и изменённым spec-файлам — это даёт быстрый и точный feedback по текущей генерации.
