# Карта решения и границы flow

```mermaid
flowchart LR
    A[Инициализация] --> B[Зависимости и doctor]
    B --> C[/autotest]
    C --> D[Подготовка запуска]
    D --> E[Выгрузка TestIt]
    E --> F[Классификация]
    F --> G[Pre-check и evidence]
    G --> H{Нужны runtime-данные\nили API-моки?}
    H --> I[Генерация тестов]
    I --> J[Healing и прогоны]
    J --> K[Единый отчёт]
```

Перед началом работы `/autotest` проверяет параметры, проект, Playwright-конфигурацию и локальные инструкции. Создаётся уникальная папка единого отчёта; при некорректном `id` или отсутствии обязательных компонентов flow останавливается до генерации.

1. Инициализация проекта.
2. Установка зависимостей и диагностика.
3. Вызов `/autotest`.
4. Подготовка запуска.
5. Выгрузка и классификация TestIt-кейсов.
6. Pre-check, доказательства, моки, генерация, healing и отчёт.

Инициализация и установка выполняются один раз для проекта; основной flow начинается с команды `/autotest` и не устанавливает пакеты самостоятельно.
