# Этап 14. Healing: исправление тестов по фактам

`playwright-test-healer` сначала запускает узкий scope. При падении он анализирует spec, исходный TestIt-кейс, pre-check, код приложения и артефакты запуска.

Если изменилось приложение или тест неверен, вносится минимальная правка только в тест. Для одного теста допускается до пяти попыток; после превышения лимита создаётся blocker с историей попыток.
