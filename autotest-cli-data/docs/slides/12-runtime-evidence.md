# Этап 10. Runtime-проверка UI: необязательная ветка

Если `@playwright/cli` уже доступен локально или в `PATH`, он может дополнить pre-check фактическими данными: accessibility snapshot, текущим URL и состоянием UI.

Если его нет, flow не меняет registry и не устанавливает пакет. Доказательствами остаются стандартные артефакты Playwright — trace, screenshot — а также код проекта и TestIt-кейсы.

В обоих вариантах основной процесс продолжается.
