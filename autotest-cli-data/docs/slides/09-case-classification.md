# Этап 7. Классификация тест-кейсов

`test-classificator` определяет тип тестирования для каждого выгруженного кейса и раскладывает копии по каталогам типов.

Например, дальнейшая обработка integration-кейсов идёт из:

```text
autotest-cli-data/test-cases/testit/integration/
```

В следующие этапы передаётся только непустой каталог выбранного `test-type` вместе со сводкой классификации. Пустой тип — корректное завершение без генерации.
