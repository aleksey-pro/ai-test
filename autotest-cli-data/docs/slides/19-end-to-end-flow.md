# Сквозной flow: 15 рабочих этапов

```text
init → install/doctor → /autotest → подготовка → извлечение → классификация
→ pre-check → evidence manifest → runtime evidence* → API mocks* → генерация
→ visual/scope → healing → расширенный прогон → единый отчёт
```

`*` Ветки выполняются по необходимости: runtime-данные — когда доступен инструмент, API-моки — когда они требуются сценарию.

На каждом этапе результат либо передаётся дальше, либо корректно завершает flow с прозрачной причиной в отчёте.
