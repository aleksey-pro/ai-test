# Этап 11. Контрактная ветка API и моки

Только для сценариев, которым необходимы API-моки, запускается отдельная ветка:

```text
Swagger/OpenAPI → swagger-parser → playwright-mock-generator
```

Сначала контракт обновляется или валидируется. При валидном контракте генерируются детерминированные fixtures, валидация, узкие `route`-обработчики и сведения о происхождении данных. При отсутствии контракта фиксируется blocker или запрашивается URL спецификации.
