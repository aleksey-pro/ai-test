# Этап 9. Evidence manifest — связь требования и проверки

Для каждого действия и ожидаемого результата создаётся компактная доказательная цепочка:

```text
строка TestIt → факт проекта / UI / OpenAPI → Playwright assertion
```

Неподтверждённые пункты не маскируются «зелёным» тестом: они остаются непокрытыми или оформляются через `test.fixme`. Это предотвращает генерацию тестов, которые формально проходят, но не доказывают требование.
