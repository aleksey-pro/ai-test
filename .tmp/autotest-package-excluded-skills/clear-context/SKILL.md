# clear-context

## Очистка контекста

### Когда использовать

Когда пользователь хочет начать с "чистого листа" — без памяти о предыдущих запросах в текущей сессии.

### Действия агента

1. **Сбросить историю разговора**
   - Агент НЕ должен ссылаться на предыдущие запросы пользователя
   - Агент НЕ должен помнить результаты предыдущих операций
   - Агент НЕ должен использовать информацию из предыдущих шагов

2. **Сбросить состояние**
   - Забыть все изменения файлов, выполненные ранее
   - Забыть все прочитанные файлы
   - Забыть все найденные совпадения

3. **Начать заново**
   - Воспринимать текущий запрос как первый в сессии
   - Не анализировать "а что было до этого"
   - Не строить цепочки на основе предыдущих действий

### Формат подтверждения

После получения команды агент отвечает:

```
Контекст очищен. Готов к новому запросу.
```

### Важно

- Это касается ТОЛЬКО памяти в текущей сессии
- Физические файлы проекта остаются неизменными
- Системные инструкции и правила поведения сохраняются
